# Architecture
- Keep AI Gateway calls server-side through the supported SDK with generated model contracts; browser views invoke authenticated Cloud functions.
- Share exact capability model allowlists between client selectors and server validation so a client cannot select unsupported research or coding models.
- Store Labs projects and job leases in Cloud, and own job observation above the route switch so navigation never interrupts completion notifications.
- Labs executes one user-triggered generation per durable job, with a unique project lock and no automatic inference replay after uncertain outcomes.
- Share Firecrawl transport and explicit credit-exhaustion detection across search and news; all other failures remain visible rather than changing providers.
- Keep the public showcase at /landing and preserve the existing / chat entry and links.
